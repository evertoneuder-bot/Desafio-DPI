# Desafio DPI — Diagnóstico por Imagem

Jogo interativo de Diagnóstico por Imagem Veterinária, desenvolvido para estimular raciocínio clínico, interpretação de exames e tomada de decisões.

## Sobre o projeto

O **Desafio DPI** é uma experiência interativa baseada em casos e desafios de diagnóstico por imagem veterinária. O projeto combina conteúdo educacional, tomada de decisões e elementos de gamificação.

## Finalidade

O jogo foi concebido para fins de educação, treinamento, prática e entretenimento, com situações simuladas ou adaptadas para a experiência de jogo.
